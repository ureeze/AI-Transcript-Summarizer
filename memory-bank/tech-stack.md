# Tech Stack

## Frontend

- React
- Vite
- TypeScript
- Tailwind CSS

## Backend

- Java 21
- Spring Boot 3.5.14
- Spring Web
- Spring Validation
- Gradle
- Gradle Wrapper 8.14.5
- JDK `HttpClient`

## AI

- OpenAI API
- Chat Completions API
- `gpt-4o-mini`
- JSON object response format

## YouTube Transcript

- 비공식 공개 자막 추출 방식

## Infrastructure

- Cloud: AWS Cloud Free Tier 기반 EC2
- Reverse Proxy: Nginx
- Container Runtime: Docker
- Deployment Orchestration: Docker Compose
- CI/CD: GitHub Actions
- Container Registry: GHCR(GitHub Container Registry)

## Environment Variables

- Backend: `OPENAI_API_KEY`
- Frontend: 운영 API base URL 또는 동일 origin `/api` 경로
- GitHub Secrets: AWS EC2 접속 및 배포에 필요한 SSH/서버 정보
