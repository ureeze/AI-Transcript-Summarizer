# Design Document

## 제품 목표

AI Transcript Summarizer는 사용자가 유튜브 영상을 입력하면 AI가 영상 자막을 기반으로 핵심 내용을 빠르게 요약해주는 웹 서비스이다.

## 대상 사용자

- 유튜브 영상 내용을 빠르게 파악하려는 사용자
- 긴 영상을 보기 전에 핵심 내용을 확인하려는 사용자
- OpenAI 기반 요약 서비스의 MVP 구현 흐름을 학습하려는 개발자

## MVP 범위

### 포함

- 유튜브 영상 URL 입력
- 유튜브 영상 ID 추출
- 유튜브 영상 자막 추출
- 3줄 요약 출력
- 핵심 포인트 최대 5개 출력
- 키워드 최대 10개 출력

### 제외

- 로그인 및 회원가입
- 결제
- 히스토리 저장
- DB 연동

## 성공 기준

- 사용자가 유튜브 영상 URL을 입력하고 요약 결과를 받을 수 있다.
- 서비스가 유튜브 영상의 자막을 가져올 수 있다.
- OpenAI API 연동이 정상 동작한다.
- 프론트엔드와 백엔드가 운영 URL에서 동작한다.

## 제품 제약

- API Key는 서버 환경변수로만 관리한다.
- 프론트엔드에 API Key를 노출하지 않는다.
- 유튜브 영상 URL과 추출 자막은 저장하지 않는다.
- 응답 시간은 목표 10초 이내, 최대 20초 이내로 한다.
